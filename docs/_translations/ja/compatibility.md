# アプリの互換性
{: #app-compatibility }

Porter は対応アプリが使う Shizuku API をサポートしています。追加の互換アプリが必要かどうかは、アプリの接続方法によって決まります。

| アプリの対応状況 | インストールするもの |
| --- | --- |
| Porter に直接対応 | Porter |
| Shizuku のみに対応 | Porter と Porter Compatibility。Shizuku がインストール済みなら Porter が置き換えます |
| 両方に対応し、サービスを選択可能 | Porter をインストールし、アプリ内で Porter を選択 |

互換アプリは、既存の Shizuku 対応アプリが Porter を見つけるために使われます。サービスの起動、許可要求の表示、アクセス許可の管理は Porter が行います。必要なアプリを使う間は互換アプリを残してください。

## Shizuku から切り替える
{: #switch-from-shizuku }

Porter に直接対応するアプリでは、Shizuku を残して構いません。Porter を起動し、アプリ内で選択して新しい要求を許可します。Shizuku に接続済みのアプリは再起動するまで Shizuku を使い続けるため、Android の設定でアプリを強制停止し、開き直してください。

Shizuku のみに対応するアプリ向けに、FOSS 版には対応する Porter Compatibility の APK が含まれています。

1. Porter をインストールして起動します。置き換えの内容を確認するまで、Shizuku は残しておいてください。
2. ホーム画面または**設定**から **Shizuku 互換性**を開きます。
3. Shizuku がインストール済みなら**置き換え**を選び、**Porter に切り替え**を確定します。Porter は Shizuku を停止し、そのアプリを置き換えて、引き継げるアクセス許可を自動的に移行します。サービスを停止できない場合は、Shizuku で停止してから再試行するよう案内します。
4. インストールされていない場合は、**自動インストール**を選びます。
5. クライアントアプリに戻ります。既存の許可を引き継がなかった場合は、アクセスを許可してください。それでも接続できないときは、Android の設定で強制停止してから開き直します。

Porter は、インストール済みのアプリとその現在のアクセス状況と照合できた許可を自動的にインポートします。Porter に既にある判断が優先されます。Shizuku のアプリ設定とペア設定は引き継がれません。アクセスのデータベースを読み取れない場合も、そのまま進めてアプリを再度許可できます。Porter は Shizuku を削除する前に引き継げるアクセス許可を保存します。インストールに失敗したときは、やり直すか、**手動**を選んでから**保存した許可をインポート**してください。

統合された置き換えは Android のメインユーザーで利用できます。別のユーザーやプロファイルに Shizuku がインストールされている場合は、そちらを個別に対処してください。Porter が他のユーザーのアプリを自動的に削除することはありません。

互換アプリの APK は、同じリリースから個別にダウンロードすることもできます。手動でインストールする場合は、Shizuku を停止してアンインストールし、Porter Compatibility をインストールしてから Porter を起動します。引き継げるアクセス許可を移行するには Porter の統合された置き換えを使ってください。置き換えのダイアログを開いただけではインポートは保存されません。端末側のインストール制限は統合インストーラーにも適用されることがあります。**手動**を選ぶと Android のインストーラーが開きます。

インストール後は、ホーム画面に、互換アプリを介して接続しているアプリの数が表示されます。カードをタップすると、バージョンの確認、同梱版の再インストール、アンインストールができます。Porter はまず自身のサービス経由でのアンインストールを試み、失敗した場合は Android のアンインストーラーを開きます。削除すると互換サポートが必要なアプリは使えなくなりますが、Porter に直接対応するアプリはそのまま動作します。互換性の画面は、開いている間は自動的に変更を確認します。
## Porter と Shizuku は同時に動作できますか？
{: #can-porter-and-shizuku-run-together }

はい。両方をインストールし、同時に動作させることができます。サービスを選べるアプリは、一度に 1 つのサービスに接続します。

**Porter Compatibility は Shizuku と同時にインストールできません。** 古いアプリに対応するため Shizuku の Android アプリ識別子を使っており、Android は両者を別々のアプリではなく、同じアプリの競合するインストールとして扱います。同じ識別子を使うフォークも同様です。

元に戻すには Porter Compatibility を削除して Shizuku を再インストールし、クライアントアプリを再起動して Shizuku でアクセスを許可してください。単独の Porter は残して構いません。

## アプリがまだ Shizuku を要求する
{: #an-app-still-asks-for-shizuku }

Porter がアクセスを提供していても、古いアプリの設定には Shizuku と表示される場合があります。これは正常です。

互換アプリは一般的な Shizuku の検出方法をカバーします。特定の画面、内部コンポーネント、非常に古い API に依存するアプリには更新が必要な場合があります。接続できないアプリがあれば、[Porter の問題報告](https://github.com/d4rken-org/porter/issues)にアプリ名とバージョンを記載してください。
