# Установка и запуск Porter
{: #install-and-start-porter }

Скачайте Porter из [GitHub Releases](https://github.com/d4rken-org/porter/releases), затем выполните следующие действия.

## Установка
{: #install }

1. Скачайте APK Porter в разделе **Assets** выбранного выпуска. ZIP- и TAR-архивы исходного кода не являются приложениями Android.
2. Откройте APK на устройстве. Если Android попросит, разрешите браузеру или файловому менеджеру устанавливать приложения из этого источника.
3. Откройте Porter.

Приложениям с прямой поддержкой Porter достаточно самого Porter. Если приложение поддерживает только Shizuku, установите также **Porter Compatibility** из того же выпуска. Сначала удалите Shizuku: компонент совместимости нельзя установить одновременно с ним. Не удаляйте компонент, пока пользуетесь такими приложениями через Porter. Подробнее в [руководстве по совместимости](/compatibility).

## Выбор способа запуска
{: #choose-how-to-start }

| Ваше устройство | Способ запуска |
| --- | --- |
| Android 11 или новее с отладкой по Wi-Fi | [Отладка по Wi-Fi](#wireless-debugging) |
| Android 7.0 или новее и компьютер | [Отладка по USB](#with-a-computer) |
| Уже есть root | [Root](#root) |

## Отладка по Wi-Fi
{: #wireless-debugging }

Нужны подключение к Wi-Fi и Android 11 или новее. Некоторые производители ограничивают отладку по Wi-Fi. Если она недоступна, используйте компьютер.

1. Включите **Для разработчиков** в настройках Android. Обычно для этого нужно открыть **О телефоне** и семь раз нажать **Номер сборки**. Расположение зависит от устройства.
2. В настройках разработчика включите **Отладку по USB** и **Отладку по Wi-Fi**. Подтвердите разрешение для сети, если появится запрос.
3. В Porter нажмите **Сопряжение** в разделе запуска через отладку по Wi-Fi. Разрешите уведомления, а при запросе также доступ к устройствам поблизости или локальной сети.
4. Откройте настройки **Отладки по Wi-Fi** Android и выберите **Подключить устройство с помощью кода подключения**. Оставьте диалог открытым.
5. Разверните уведомление сопряжения Porter и введите показанный Android код. Дождитесь успешного сопряжения.
6. Вернитесь в Porter и нажмите **Запустить** в разделе отладки по Wi-Fi.
7. Убедитесь, что Porter сообщает о работающей службе.

При остановке Porter настройки отладки Android остаются включёнными. Когда доступ больше не нужен, их можно выключить в настройках разработчика.

Обычно сопряжение достаточно выполнить один раз. Запуск службы является отдельным шагом, который нужно повторять после перезагрузки устройства. Если Android забудет сопряжение, выполните эти действия снова.

Если в **Настройках**, **Запуск**, **Способ сопряжения** выбран диалог внутри приложения, дождитесь обнаружения службы и введите код в этом диалоге Porter. Если нужен порт, используйте порт сопряжения из диалога Android с кодом, а не порт подключения на главном экране отладки по Wi-Fi.

## С помощью компьютера
{: #with-a-computer }

1. Установите на компьютер [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) от Google.
2. Включите настройки разработчика и **Отладку по USB** на устройстве Android.
3. Подключите устройство USB-кабелем с передачей данных. Разблокируйте его и разрешите отладочное подключение. Авторизуйте только доверенные компьютеры.
4. Откройте терминал в папке Platform-Tools и выполните `adb devices`. В Windows PowerShell используйте `./adb.exe devices`; в macOS или Linux используйте `./adb devices`, если ADB отсутствует в PATH.
5. В Porter найдите раздел запуска с компьютера и нажмите **Показать команду**. Выполните именно эту команду на компьютере, при необходимости изменив префикс исполняемого файла `adb`, как описано выше.
6. Убедитесь, что Porter работает. После этого кабель можно отключить.

Если подключено несколько устройств, вставьте `-s DEVICE_SERIAL` сразу после `adb` в показанной команде. Используйте серийный номер устройства с Porter из вывода `adb devices`.

После обновления или переустановки Porter скопируйте команду заново: путь может измениться. Не используйте команду от Shizuku или другой установки.

## Root
{: #root }

Этот способ предназначен для устройств с уже работающим root-доступом. Установка Porter не предоставляет root устройству.

1. Откройте Porter и нажмите **Запустить** в разделе root.
2. Подтвердите запрос Porter в менеджере root.
3. Убедитесь, что Porter работает и указывает root как режим запуска.

Перед переключением между root и отладочным доступом остановите текущую службу Porter.

## Разрешить доступ приложению
{: #allow-an-app }

Откройте нужное приложение, включите интеграцию с Porter или Shizuku и подтвердите запрос Porter. Разрешайте доступ только доверенным приложениям: они смогут выполнять действия с отладочными или root-правами Porter.

Чтобы отозвать доступ, откройте **Приложения** в Porter и выключите разрешение нужного приложения. Porter и Shizuku хранят разрешения отдельно.

Чтобы приостановить доступ всех приложений, выключите **Разрешить доступ приложениям** вверху этого экрана. Индивидуальные разрешения сохранятся. Включите переключатель снова, чтобы возобновить доступ. Уже запущенные команды оболочки могут продолжать работу во время паузы.

Если в приложении есть выбор службы, выберите Porter. Следуйте инструкции самого приложения. Если после изменения нужен перезапуск, нажмите **Остановить** в настройках приложения Android и откройте его снова.

## Остановка Porter
{: #stop-porter }

Нажмите карточку работающего Porter на главном экране, затем **Остановить Porter**. Подключённые приложения потеряют доступ до следующего запуска Porter.

## Обновление Porter
{: #update-porter }

Установите новый APK поверх существующего приложения и снова запустите Porter. Если используете Porter Compatibility, обновите его из того же выпуска. Android требует совпадающие подписи для обновлений; при отказе см. [проблемы установки](/troubleshooting#android-wont-install-an-apk).
