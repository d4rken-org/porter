# Совместимость приложений
{: #app-compatibility }

Porter поддерживает API Shizuku, используемые совместимыми приложениями. Необходимость дополнительного компонента зависит от способа подключения приложения.

| Что поддерживает приложение | Что установить |
| --- | --- |
| Porter напрямую | Porter |
| Только Shizuku | Porter и Porter Compatibility; сначала удалите Shizuku |
| Оба варианта с выбором службы | Porter, затем выберите Porter в приложении |

Компонент совместимости помогает существующим приложениям Shizuku найти Porter. Сам Porter запускает службу, показывает запросы разрешений и управляет доступом. Оставляйте компонент установленным, пока используете приложения, которым он нужен.

## Переход с Shizuku
{: #switch-from-shizuku }

Для приложения с прямой поддержкой Porter можно оставить Shizuku установленным. Запустите Porter, выберите его в приложении и подтвердите новый запрос. Если приложение требует перезапуска, принудительно остановите его в настройках Android и откройте снова.

Для приложения, поддерживающего только Shizuku:

1. Остановите Shizuku и удалите его приложение-менеджер. Использующие Shizuku приложения удалять не нужно.
2. Установите Porter и APK Porter Compatibility из одного выпуска.
3. Запустите Porter.
4. Принудительно остановите клиентское приложение в настройках Android, откройте его снова и включите интеграцию с Shizuku.
5. Подтвердите запрос доступа от Porter.

Прежние разрешения Shizuku не переносятся. Снова выберите приложения, которым разрешён доступ через Porter.

## Могут ли Porter и Shizuku работать одновременно?
{: #can-porter-and-shizuku-run-together }

Да. Оба приложения могут быть установлены и запущены одновременно. Приложение с выбором службы подключается к одной из них за раз.

**Porter Compatibility нельзя установить одновременно с Shizuku.** Для поддержки старых приложений он использует Android-идентификатор Shizuku. Android считает их конкурирующими установками одного приложения, а не разными приложениями. Это относится и к форкам с тем же идентификатором.

Для возврата удалите Porter Compatibility и установите Shizuku. Перезапустите клиентское приложение и разрешите доступ в Shizuku. Самостоятельный Porter можно оставить установленным.

## Приложение всё ещё просит Shizuku
{: #an-app-still-asks-for-shizuku }

В настройках старого приложения может оставаться название Shizuku, даже когда доступ предоставляет Porter. Это нормально.

Компонент поддерживает распространённые способы обнаружения Shizuku. Приложения, зависящие от конкретных экранов, внутренних компонентов или очень старых API, могут нуждаться в обновлении. Если приложение не подключается, укажите его название и версию в [сообщении об ошибке Porter](https://github.com/d4rken-org/porter/issues).
