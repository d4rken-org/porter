# Akses ADB untuk aplikasi Anda
{: #adb-access-for-your-apps }

Porter adalah fork [Shizuku](https://github.com/thedjchi/Shizuku) yang minimalis dan terus dipelihara. Porter memberikan akses ADB kepada aplikasi Android melalui API Shizuku, dengan dukungan root opsional.

Anda memilih aplikasi yang boleh menggunakannya.

## Untuk pengguna
{: #for-users }

1. Unduh Porter dari [GitHub Releases](https://github.com/d4rken-org/porter/releases).
2. Ikuti [panduan pemasangan dan menjalankan layanan](/setup).
3. Buka aplikasi yang didukung dan setujui permintaan akses Porter.

Diperlukan Android 7.0 atau lebih baru. Pada Android 11 atau lebih baru, proses debug nirkabel memungkinkan Porter dijalankan tanpa komputer. Perangkat lama memerlukan komputer atau root.

Bantuan lainnya: [kompatibilitas aplikasi](/compatibility) dan [pemecahan masalah](/troubleshooting).

## Sudah menggunakan Shizuku?
{: #already-using-shizuku }

Porter memiliki identitas aplikasi sendiri dan dapat berjalan bersama Shizuku. Aplikasi yang hanya mengenali Shizuku memerlukan pendamping opsional Porter Compatibility, yang menggantikan aplikasi Shizuku terpasang.

[Temukan pengaturan yang tepat untuk aplikasi Anda](/compatibility).

## Mengapa Porter dibuat
{: #why-porter-exists }

Saya menggunakan Shizuku dalam aplikasi saya, [SD Maid SE](https://github.com/d4rken-org/sdmaid-se) dan [Butler](https://github.com/d4rken-org/butler). Aplikasi Shizuku asli sudah tidak dipelihara secara aktif, jadi saya membuat Porter agar tersedia alternatif yang minimalis, stabil, dan terus dipelihara untuk aplikasi yang memerlukan akses ADB.

## Untuk pengembang
{: #for-developers }

Pengembang lain dipersilakan mendukung izin Porter secara langsung. [Tambahkan dukungan langsung Porter ke aplikasi Anda](/developers).

## Perlu bantuan?
{: #need-help }

Lihat [pemecahan masalah](/troubleshooting), atau [laporkan masalah](https://github.com/d4rken-org/porter/issues).

Porter merupakan kelanjutan independen Shizuku, berdasarkan karya [RikkaApps](https://github.com/RikkaApps/Shizuku), [thedjchi](https://github.com/thedjchi/Shizuku), dan para kontributornya.
