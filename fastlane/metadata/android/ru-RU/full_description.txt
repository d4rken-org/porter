<i>Porter</i> даёт твоим приложениям ADB-доступ, чтобы они могли делать то, для чего обычно нужен компьютер. Ты решаешь, какие приложения его получат.

С ADB-доступом приложения могут управлять другими приложениями, очищать скрытый кеш или открывать файлы, которые Android обычно блокирует. Как правило, для этого нужно подключить компьютер и вводить команды. Porter один раз запускает небольшую службу, и одобренные тобой приложения используют её прямо на устройстве.

Porter является поддерживаемым форком Shizuku. Он остаётся компактным и стабильным для приложений, которые от него зависят.

<b>Запускай как удобно</b>
- Отладка по Wi-Fi на Android 11 и новее, без компьютера
- Отладка по USB с компьютером, на Android 7.0 и новее
- Root, если на устройстве уже есть root
- Запуск при загрузке и Watchdog, который перезапускает Porter в случае сбоя (Android 11+ или root)
- Поддержка Android TV: сопряжение можно завершить с помощью пульта

<b>Всё под твоим контролем</b>
- Приложения сначала должны запросить доступ, а ты разрешаешь или запрещаешь его каждому
- Смотри, какие установленные приложения поддерживают Porter и какие из них подключены
- Отзывай доступ в любой момент или приостанавливай его сразу для всех приложений
- Управляй Porter из приложений автоматизации с помощью интентов

<b>Приложения для Shizuku</b>
Приложениям с прямой поддержкой Porter нужен только Porter. Приложениям, которые поддерживают только Shizuku, нужен дополнительный шаг, описанный на странице https://porter.darken.eu/compatibility

<b>Для разработчиков приложений</b>
Добавь прямую поддержку Porter в своё приложение: https://porter.darken.eu/developers

<b>Конфиденциальность</b>
Без рекламы, без отслеживания, без аккаунта. Доступ получают только одобренные тобой приложения. У Porter открытый исходный код.

<b>Служба специальных возможностей</b>
Porter включает необязательную службу специальных возможностей, которая используется только на Android TV для сопряжения при настройке отладки по Wi-Fi. Она считывает код сопряжения с экрана сопряжения Android и отключается сама, как только сопряжение завершено. Никакую другую информацию она не собирает и не передаёт.

Porter основан на Shizuku от RikkaApps и на последующей работе по поддержке от thedjchi и других участников. Porter не связан с разработчиками Shizuku.
