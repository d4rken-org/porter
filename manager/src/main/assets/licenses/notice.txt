Porter

Based on Shizuku by RikkaApps and contributors and the Shizuku maintenance fork by thedjchi and contributors.
https://github.com/RikkaApps/Shizuku
https://github.com/thedjchi/Shizuku

Porter modifications include independent application identity, provider routing, optional legacy compatibility, authorization handling, service coexistence, release configuration and artwork.

The original Shizuku name and artwork are not used as Porter's product identity. The Shizuku icon is shown only to identify Shizuku compatibility, using the upstream artwork from the baseline preceding 6c796250. Legacy API identifiers remain where required for protocol interoperability and in the optional compatibility companion.

Porter icon, mascot and banner artwork by Max Patchs.
